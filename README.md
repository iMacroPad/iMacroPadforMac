# iMacroPad for Mac

Signed and notarised builds of the iMacroPad Mac companion. Each version is a [release](../../releases); the newest is always at
`https://github.com/iMacroPad/iMacroPadforMac/releases/latest/download/iMacroPad-for-Mac.zip`.

Get it from [imacropad.app/download](https://www.imacropad.app/download/). Check a download with `shasum -a 256 iMacroPad-for-Mac.zip` against the release's `latest.json`.
